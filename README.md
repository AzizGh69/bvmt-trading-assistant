# BVMT Trading Assistant

An intelligent trading assistant for the Tunis Stock Exchange (BVMT): market
data, forecasts, anomaly detection, portfolio optimisation, AI agents and a
chatbot.

**Status: being built.** The specification is in [BRIEF.md](BRIEF.md).
